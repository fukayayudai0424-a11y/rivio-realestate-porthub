# PortHub Real Estate Mock Site

不動産向け PortHub Isometric Pattern の仮サイト一式です。

## ファイル構成

- `index.html` トップ（ハブ導線）
- `buy.html` 買いたい
- `rent.html` 借りたい
- `sell.html` 売りたい
- `owner.html` 貸したい
- `about.html` 会社案内
- `recruit.html` 採用情報
- `contact.html` お問い合わせ（LINE + フォーム）
- `privacy.html` プライバシーポリシー
- `assets/css/styles.css` スタイル
- `assets/js/main.js` ナビとフォーム挙動

## 使い方

1. `index.html` をブラウザで開く
2. 各導線を確認する
3. 文言・会社情報・リンク先を実案件向けに差し替える

## 注意

- 仮サイトのため、フォームは送信シミュレーションのみ（実送信なし）
- 実公開前に法務文面（プライバシー等）を必ず差し替える
